# Baseline — 프론트엔드 v2

이 문서는 하나의 팀·회사가 여러 프론트엔드 프로젝트에 공통 적용하는 기준입니다. Baseline은 질문, 경계, 조직 공통 기술 스택 정책의 정본이고 프로젝트 Context는 해당 프로젝트에서 실제로 선택한 기술, 버전, 명령어, 편차와 근거를 소유합니다. Baseline을 프로젝트 안에 복사하지 않고 정본을 참조합니다.

## Baseline 구성

이 인덱스와 아래의 다섯 구성 파일을 합쳐 하나의 완전한 Baseline으로 취급합니다. 프로젝트 감사 또는 셋업 전에 모든 구성 파일을 다음 순서대로 완전히 읽습니다. 이 링크들은 선택적 참고자료가 아니라 Baseline 구성 선언입니다.

1. [Context 주제](_context-topics.md)
2. [프론트엔드 기술 스택 기준](_frontend-technology-stack.md)
3. [원자적 경계](_atomic-boundaries.md)
4. [대조 상태 용어](_comparison-statuses.md)
5. [Context 경계 적용 지침](_context-boundary-guidance.md)

인덱스만 읽고 Baseline 기준을 추론하지 않습니다. 구성 파일이 없거나 읽을 수 없으면 누락된 기준을 임의로 보완하지 말고 Baseline 결함 또는 작업 차단으로 보고합니다.
